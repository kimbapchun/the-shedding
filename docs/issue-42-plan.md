## 📝 작업 내용
서버에서 역할별 캐릭터를 생성하고, 소유자의 게임플레이 입력을 서버에서 검증한 뒤 인벤토리·체력·상태이상·손전등 상태를 복제한다.
기존 미커밋 Bootstrap.unity 및 FirstFloorScene.unity 변경은 보존하고 커밋에서 제외한다.

### 주요 변경사항
1. **역할·스폰:** 접속 명단을 서버에서 섞고 등록된 프리팹을 역할에 맞춰 선택한다. 강도 수는 기본 `ceil(플레이어 수 / 4)`, 가족 역할은 각각 최대 1명이다. 가족 자동 배정 순서는 엄마 → 아기 → 아빠 → 개이며, 로비 역할 선택 UI는 별도 범위다. 중복 스폰을 막고 퇴장 시 자리를 반환한다. 늦은 접속은 기존 역할을 바꾸지 않고 빈 역할을 배정하며, 재접속도 새로운 연결로 재배정한다. 로비 복귀·서버 종료 시 명단을 비운다.
2. **함정·아이템:** 설치 성공 시 서버 종료 시각을 복제해 프리뷰를 숨긴다. 설치 프리팹 검증·스폰에 실패하면 아이템과 쿨타임을 보존한다. 실제 설치물은 NetworkObject로 복제하며 늦은 접속도 받는다. H는 강도 회복, G는 선택 아이템 버리기다. 서버 보유 여부·행동 가능 여부를 검증하고 버리기는 스폰 성공 후 소모한다.
3. **전투·손전등:** 공격과 자세 변경 요청을 서버로 중계하고 체력·상태이상·스턴·슬로우 종료 시각과 자세를 복제한다. 공격 애니메이션 트리거도 서버 NetworkAnimator로 전달한다. 복합 콜라이더는 공격당 한 번만 판정한다. 손전등 토글은 소유자 RPC로 검증하고 켜짐 상태를 복제한다. 서버 어댑터에서 스턴을 판정하므로 비소유 컨트롤러가 꺼져 있어도 동작하며 소유자의 로컬 판정과 중복되지 않는다.

### 검증
- Unity 6000.5.3f1의 EditMode 회귀 테스트와 PlayMode 통합 테스트를 사용한다.
- PlayMode는 실제 UnityTransport 루프백 연결의 호스트·원격·늦은 접속 클라이언트를 생성한다. 같은 프로세스의 복제본 콜라이더는 서버 Physics 판정에 섞이지 않게 테스트에서만 비활성화한다.
- 확인 항목: 비소유 로버 컨트롤러 비활성화, 원격/호스트 손전등, 가족 스턴 복제와 만료, 손전등 늦은 접속, 원격 공격과 중복 쿨타임 요청, 회복·소모 복제, 원격 아기 훔치기·버리기, 호스트/원격 엄마 설치, 쿨타임 중 프리뷰 숨김과 만료 후 재표시, 설치 함정의 늦은 접속 복제, 행동 불가 토글 거절, 사망 복제.
- 단위 테스트: 역할 인원 제한·중복 요청·자리 반환·명단 초기화·누락 프리팹, 비활성 컨트롤러 타이머, 스턴 행동 차단, 설치 실패 시 아이템 보존, 기존 인벤토리·게임 매니저 규칙.
- PlayMode 통합 테스트: 2026-10-27 통과 (1개, 실패 0개).
- EditMode 전체 테스트: 2026-10-27 통과 (82개, 실패 0개).

### 남은 수동 확인과 범위
- [ ] 서로 다른 기기의 Relay 연결에서 실제 입력·카메라·화면·지연 환경을 확인한다. 루프백 통합 테스트와 별도로 수행할 배포 전 점검이다.
- 함정 설치용·프리뷰 프리팹은 기본 표시용 마커다. 기존 프로젝트에 함정 종류별 발동·발자국·비명 효과 코드가 없으므로 이 변경은 설치물의 네트워크 생성까지 다룬다.
- 역할 선택 UI와 GameManager 라운드/재접속 유예 정책의 네트워크 연결은 이번 자동 스폰 정책과 별도다.
- 이동은 기존 소유자 권위를 유지한다. 공격·상호작용은 서버가 받은 위치를 기준으로 판정한다.
